# Start here

Your assignment is in the folder **`analyst-agent-assignment/`**.

1. Open **`analyst-agent-assignment/README.md`** — what you are building and where everything is.
2. Open a terminal (**File → New → Terminal**). It starts inside the assignment folder. Run:

   ```bash
   python -m agent.main --doctor     # are the four outside services reachable?
   ./check.sh env                    # is this container healthy?
   ```

   Both should be clean. If not, it is a platform problem, not yours — see
   `analyst-agent-assignment/TROUBLESHOOTING.md` and tell your trainer.
3. Read **`analyst-agent-assignment/ASSIGNMENT.md`** and start with Milestone 1.

Only this workspace folder is saved. Anything you put elsewhere in the
container disappears when it restarts.
